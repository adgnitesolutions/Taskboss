TASKBOSS AI — iPhone Home Screen edition

Host the contents of this folder on a static HTTPS host (e.g. GitHub Pages). Do not upload your task backups to the host. Open the resulting URL in Safari, tap Share > Add to Home Screen, enable Open as Web App if shown, then Add. Open from the Home Screen and allow initial caching. Test offline before relying on it.

No APIs, accounts inside the app, or external scripts. Data remains in browser storage; clearing website data or moving origins can erase access. Export backups regularly. V3 backups can be imported in Settings.

In-app reminders work only while the app can execute. Export daily recurring calendar events and individual task events for OS alerts, and verify them in Calendar. No push server is included. Voice support depends on device. No native IPA or App Store installation is provided.
